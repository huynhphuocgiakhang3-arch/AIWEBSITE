# HPGK AGENT v0.6 architecture

## Goal
Keep the web fast on Vercel while moving all expensive training/inference into on-demand cloud sessions. No personal device needs to stay on.

```text
                    HPGK AGENT
                         │
             ┌───────────┴───────────┐
             │                       │
          Vercel                  Kaggle
          Web/API              GPU training
             │                       │
             │                  checkpoint
             │                       │
             └──────────→ Model Hub ←┘
                           │
                    optional ZeroGPU
                           │
                       inference
```

## Cost model
- Vercel web: free tier as available.
- Kaggle: GPU is quota-limited; current public Kaggle material describes a 30 GPU-hour/week limit for typical users. Sessions are finite, so checkpoints are mandatory.
- Hugging Face ZeroGPU: optional, on-demand, quota-limited; not a 24/7 server.

## What “daily learning” means in v0.6
The system records validated experiences and produces a queue/manifest. Training is only performed when a GPU session is available. The model is promoted only after evaluation. This is continual-learning infrastructure, not magical unattended training.

## No fake AI
If no promoted checkpoint exists, the Web UI reports `MODEL_NOT_READY` instead of generating a pretend answer.
