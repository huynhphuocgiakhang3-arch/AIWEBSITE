# V0.6 setup — do this in order

### A. Keep Vercel
Your existing Vercel deployment stays the same. Push this version and redeploy.

### B. Kaggle
1. Create a Kaggle Notebook.
2. Enable a GPU accelerator.
3. Upload/attach the project's `ai/data/raw` dataset.
4. Upload `notebooks/HPGK_AGENT_v0.6_Kaggle.ipynb`.
5. Run all cells.
6. The first run creates `checkpoints/hpgk-v0.6.pt` and a manifest.
7. Later sessions use `--resume`.

### C. Model Hub (optional but recommended)
Create a Hugging Face model repository and set Kaggle Secrets:
- `HF_TOKEN`
- `HF_MODEL_REPO` (example: `yourname/hpgk-agent-v06`)
Then run `python ai/scripts/publish_model.py`.

### D. Inference
For a truly $0 setup, do not promise 24/7 inference. Use the optional ZeroGPU lane only when your account is eligible and quota is available. Otherwise leave `HPGK_INFERENCE_URL` unset; the web remains online and clearly reports that the model is offline/on-demand.

### E. Vercel variables when a worker exists
`HPGK_INFERENCE_URL=https://...`
`HPGK_WORKER_TOKEN=...` (optional)
`HPGK_MODEL_READY=true`
Then redeploy.
