# HPGK v2.1 — Agent + RAG Core

## Luồng
Intent → Retrieval → Context → Plan → Tool → Verify → Self-check.

## Retrieval
Index nhẹ được tải trước; knowledge packs được mở lười (lazy) khi domain có kết quả. Xếp hạng gồm exact phrase, title match, term match và rerank đơn giản.

## Project understanding
ZIP được kiểm tra giới hạn kích thước/số mục, đọc directory mà không tự động thực thi code. Các file code/tài liệu quan trọng được trả về để đưa vào context ở bước tiếp theo.

## Performance
Không import toàn bộ packs vào client bundle. UI không cần chờ knowledge đầy đủ để render. Server cache index/packs trong process.

## Safety
Không chạy code upload. ZIP bị giới hạn 40 MB/6.000 entries ở route mẫu. Production nên bổ sung kiểm tra traversal/symlink, quota, timeout và content validation.
